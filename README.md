# 🎵 Sistema Musical

## 📌 Sobre o Projeto

O Sistema Musical é um projeto desenvolvido em HTML5 e CSS3 com o objetivo de criar uma plataforma simples para organizar e gerenciar informações sobre artistas e músicas.

O sistema possui uma interface organizada, com telas de login, menu principal, cadastro de artistas, cadastro de músicas e biblioteca musical.

## 🎯 Objetivo

Praticar os conhecimentos de desenvolvimento web, utilizando HTML para estruturar as páginas e CSS para estilizar os elementos, criando um sistema visualmente organizado e fácil de utilizar.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, cores, botões, formulários e tabelas.
- **Visual Studio Code:** editor de código.

## 📂 Estrutura dos Arquivos

- `login.html` – Tela de acesso ao sistema.
- `index.html` – Menu principal com as opções de navegação.
- `cadastro_artista.html` – Página de cadastro de artistas.
- `cadastro_musica.html` – Página de cadastro de músicas.
- `listagem_musicas.html` – Biblioteca com listagem e filtros de músicas.
- `styles.css` – Arquivo principal de estilos utilizado em todas as páginas.

## ✨ Funcionalidades

- Tela de login com usuário e senha.
- Menu principal com opções de navegação.
- Área para gerenciamento de artistas.
- Formulário para cadastro de músicas.
- Campos para título, álbum, gênero, link do YouTube e letra da música.
- Biblioteca musical com tabela de músicas cadastradas.
- Filtros por nome, artista e gênero.
- Botões de editar, excluir e assistir músicas.
- Layout responsivo para diferentes tamanhos de tela.

## 🎨 Identidade Visual

O projeto utiliza uma combinação de cores com destaque para o azul, verde, vermelho e cinza claro. Os elementos possuem bordas arredondadas, sombras e efeitos ao passar o mouse, deixando a interface mais agradável.

## ▶️ Como Executar

1. Baixe ou clone o projeto.
2. Salve todos os arquivos na mesma pasta.
3. Abra a pasta no Visual Studio Code.
4. Abra o arquivo `login.html` no navegador.
5. Utilize a navegação do sistema para acessar as demais páginas.

**Credenciais de teste:**

- Usuário: `admin`
- Senha: `123`

## 📚 Considerações Finais

O desenvolvimento do Sistema Musical foi importante para colocar em prática os conhecimentos aprendidos nas aulas. Com o projeto, foi possível entender melhor como estruturar páginas HTML, aplicar estilos com CSS, criar formulários e organizar a navegação de um site.

O projeto também ajudou a desenvolver habilidades de organização, atenção aos detalhes e resolução de problemas durante a programação. Algumas funcionalidades ainda precisam de integração com banco de dados e outras tecnologias para funcionarem completamente.
